# 🚀 Frameworks Directory (`frameworks/`)

This directory contains production-grade, battle-tested framework guides across Frontend, Backend, and Mobile platforms.

## Directory Structure

- [`frontend/`](frontend/):
  - [`nextjs.md`](frontend/nextjs.md): Next.js App Router, Server Components (RSC), Server Actions, Caching, Edge runtime, and Auth.
  - [`react.md`](frontend/react.md): React 18/19 Core, Concurrency, Hooks, Error Boundaries, and Render Trees.
- [`backend/`](backend/):
  - [`fastapi.md`](backend/fastapi.md): Python FastAPI, Pydantic v2, AsyncIO, Lifespan contextmanager, Async SQLAlchemy 2.0 / Asyncpg, OAuth2/JWT, and Gunicorn/Uvicorn tuning.
  - [`nestjs.md`](backend/nestjs.md): TypeScript NestJS, Enterprise Hexagonal Architecture, Dynamic Modules, CQRS, Guards, Pipes, Interceptors, and Microservices.
  - [`django.md`](backend/django.md): Django 5 + DRF, ORM Optimization (`select_related`, `prefetch_related`), Atomic Transactions, Celery Async Tasks with Redis, and Security Hardening.
  - [`go-gin-axum.md`](backend/go-gin-axum.md): High-Throughput Microservices in Go (Gin/Chi) and Rust (Axum 0.7+), Zero-Allocation Handlers, Connection Pooling, and Graceful Shutdown.
  - [`dotnet-aspnet.md`](backend/dotnet-aspnet.md): C# .NET 8/9 Minimal APIs, EF Core DbContext Pooling, Carter, Polly v8 Resilience Pipelines, Rate Limiting, Kestrel Tuning, and Native AOT.
  - [`express.md`](backend/express.md): TypeScript Express 5.x, Middleware Composition, Zod Validation, Error Boundaries, and Production Multi-Stage Docker.
  - [`spring-boot.md`](backend/spring-boot.md): Spring Boot 3.3+, Java 21 LTS, Virtual Threads (Project Loom), Spring Security 6, and JPA/Hibernate.
- [`mobile/`](mobile/):
  - [`react-native-expo.md`](mobile/react-native-expo.md): Expo Router, Native Modules, Hermès engine, and Performance tuning.
