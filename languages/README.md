# 💻 Language Mastery Guides (`languages/`)

This directory provides deep idiomatic conventions, strict type standards, memory safety guidelines, and error patterns across major production programming languages.

## Language Standards

- [`typescript.md`](typescript.md): Strict compiler options, type narrowing, generics, Zod integration, and monorepo structure.
- [`python.md`](python.md): Modern Python 3.11+, complete type hinting, Ruff linter/formatter, UV package manager, and AsyncIO.
- [`golang.md`](golang.md): Idiomatic Go, error handling, Goroutines and channels, context propagation, and interface design.
- [`rust.md`](rust.md): Ownership, lifetimes, Result/Option handling with `anyhow`/`thiserror`, Tokio async runtime.
- [`java.md`](java.md): Modern Java 21+ LTS, Records, Sealed Classes, Pattern Matching, Virtual Threads, Structured Concurrency, and GraalVM native images.
- [`sql.md`](sql.md): ANSI SQL, CTEs, Window functions, index-friendly predicates, and ACID transaction locks.
